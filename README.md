# Job Portal – Full‑Stack Web Application  

## 📌 Overview  
The **Job Portal** is a full‑stack web application designed to streamline recruitment workflows. It enables employers to post jobs, track applicants, and manage profiles, while providing candidates with a secure and user‑friendly platform to apply for opportunities.  

---

## 🚀 Features  
- **Secure Authentication:** User login, signup, and role‑based access control.  
- **Job Postings:** Employers can create, edit, and manage job listings.  
- **Applicant Tracking:** Recruiters can view, filter, and shortlist candidates.  
- **Profile Management:** Candidates can update resumes, skills, and personal details.  
- **REST API Integration:** Dynamic data handling with scalable backend services.  
- **Responsive UI:** Built with React, Vite, and TailwindCSS for seamless cross‑platform experience.  

---

## 🛠️ Tech Stack  
| Frontend | Backend | Database | Tools |
|----------|---------|----------|-------|
| React, Vite, TailwindCSS | Node.js, Express.js | MongoDB / PostgreSQL | Git, npm, REST APIs |

---

## ⚙️ Installation & Setup  

1. **Clone the repository**  
   ```bash
   git clone https://github.com/your-username/job-portal.git
   cd job-portal
   ```

2. **Install dependencies**  
   ```bash
   npm install
   ```

3. **Configure environment variables**  
   Create a `.env` file with:  
   ```
   PORT=5000
   MONGO_URI=your_database_url
   JWT_SECRET=your_secret_key
   ```

4. **Run the development server**  
   ```bash
   npm run dev
   ```
